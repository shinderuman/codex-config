# CodexVault規則
- `/Volumes/CodexVault`はCodex専用の高速な作業・一時バックアップ用ストレージとして優先する。
- SATA SSD 2枚をRAID 0にした約240GBとして扱う。この用途ではRAID 0の耐障害性警告は不要。
- 使用前にマウント状態と空き容量を確認する。
- 書き込み失敗を避けられる範囲で空き容量をぎりぎりまで使用してよい。
- ディレクトリ構成・一時データ整理は作業目的に応じて判断してよい。
- 既存HDD上の一時バックアップを移す場合、移動先の件数・容量・チェックサム検証後に元を整理する。
- 接続されているという理由だけで既存バックアップを移動しない。
- バックアップ後は用途に応じて件数・容量・チェックサム等を検証する。
